CAFE YOLO WEBSITE

Responsive static HTML/CSS/JS website for Cafe YOLO, Malegaon.

Features:
- Mobile + desktop responsive design
- Cafe YOLO original photos
- Menu showcase only (no food ordering)
- Table booking through WhatsApp
